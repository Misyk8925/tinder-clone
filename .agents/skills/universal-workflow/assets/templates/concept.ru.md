# Концепт: Лимит длины био

Статус: ЧЕРНОВИК · Slug: `bio-max-length`

Владелец профиля может сохранить био длиннее 500 символов, и карточки в ленте переполняются. Отклоняем био длиннее 500 символов на существующем write-path профиля.

## В скоупе

| ID | Часть | Готово, когда |
|---|---|---|
| FR-1 | Отклонять био длиннее 500 символов | 501 символ → `BIO_TOO_LONG` |
| NFR-1 | Валидация остаётся быстрой | p95 < 50 ms при 50 rps |

## Вне скоупа

| Что | Почему |
|---|---|
| Модерация контента | Отдельная фича |
| Смена лимита 500 | Зафиксирован для v1 |
